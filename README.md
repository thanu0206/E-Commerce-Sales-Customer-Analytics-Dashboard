# E-Commerce Sales & Customer Analytics Dashboard

An interactive Excel dashboard that analyzes e-commerce sales and customer behavior to find revenue trends, top products, and customer insights.

## 📊 Dashboard Preview


![Dashboard](dashboard.png)



## 🎯 Objective
To help a business understand sales performance, customer segments, and product trends, and make data-driven decisions.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers
- Formulas (SUMIFS, XLOOKUP, etc.)
